# ✅ StudentCheck — ระบบเช็คชื่อนักเรียนออนไลน์

ระบบเช็คชื่อนักเรียนสำหรับครูประจำชั้นและครูประจำวิชา ใช้งานผ่านเว็บเบราว์เซอร์ทั้งบนมือถือและคอมพิวเตอร์ เป็นไฟล์ HTML ไฟล์เดียว ฝากบน **GitHub Pages** ได้ฟรี ไม่ต้องมีเซิร์ฟเวอร์ และเชื่อมกับ **Google Sheets** เพื่อเก็บข้อมูลถาวรและใช้ร่วมกันหลายเครื่องได้

> เบื่อกับกระดาษเช็คชื่อ? ลองใช้ StudentCheck ดูครับ

---

## ✨ ความสามารถ

### 📋 เช็คชื่อ
- กดสถานะ **มา / สาย / ลา / ขาด** ทีละคน (กดซ้ำเพื่อยกเลิก) พร้อม**ช่องเหตุผล**รายคน
- ปุ่ม **✓ ทุกคนมา** สำหรับคนที่ยังไม่ได้เช็ค และปุ่ม **↺ ล้าง**
- **📝 หมายเหตุประจำวัน** ของทั้งห้อง เช่น "กิจกรรมกีฬาสี" หรือ "ฝนตกหนัก"
- สรุปตัวเลขด้านบน และ**แถบความคืบหน้าแบ่งสี**ตามสถานะ
- เลือกวันย้อนหลังหรือล่วงหน้าได้ และค้นหาชื่อหรือเลขประจำตัวได้
- **เช็คชื่อรายวิชา** แยกจากโฮมรูม โดยใช้รายชื่อนักเรียนชุดเดียวกัน

### 👥 นักเรียนและห้องเรียน
- เพิ่ม แก้ไข และลบนักเรียนได้ มีหลายห้องเรียน ระบุครูประจำชั้นและ**ครูร่วม**ได้
- **นำเข้ารายชื่อจาก Excel** (.xlsx / .xls / .csv) ระบบหาคอลัมน์ให้อัตโนมัติ
- จัดการ**รายวิชา** (รหัสวิชา ชื่อวิชา ครูผู้สอน) และคัดลอกรายวิชาไปห้องอื่นได้

### 📈 แดชบอร์ด
- ดูได้แบบ **วันเดียว / รายเดือน / กำหนดช่วงเวลาเอง** ทั้ง**ห้องเดียว**หรือ**ทุกห้อง**
- แสดงอัตรามาเรียน จำนวนแต่ละสถานะ และกราฟรายวัน
- **Ranking** แบ่งเป็น อันดับห้องเรียน, นักเรียนมาเรียนดีเด่น, ขาดมากที่สุด และมาสายมากที่สุด
- **📷 ส่งออกเป็นรูปภาพ** แล้วแชร์เข้า LINE ได้ทันที

### 📊 รายงาน
- รายงานรายวัน
- รายงานย้อนหลังรายเดือนแบบตาราง (นักเรียน × วันที่)
- รายชื่อนักเรียนที่ขาดหรือสายบ่อย (ตั้งเกณฑ์จำนวนครั้งได้)
- สรุปทุกวิชา (นักเรียน × วิชา)
- **ส่งออก Excel** และ**สั่งพิมพ์**ได้ทุกรายงาน

### 💬 LINE
- สร้างข้อความสรุปการเช็คชื่อ (จำนวนแต่ละสถานะ รายชื่อพร้อมเหตุผล และหมายเหตุประจำวัน) แล้วเปิดแอป LINE ให้เลือกกลุ่มส่ง
- ส่งรูปสรุปจากแดชบอร์ดเข้า LINE ได้

### ☁️ Google Sheets
- บันทึกขึ้นชีตอัตโนมัติทุกครั้งที่เช็คชื่อ และดึงข้อมูลจากเครื่องอื่นทุก 1 นาที
- **ใช้งานแบบออฟไลน์ได้** ระหว่างเน็ตหลุดยังเช็คชื่อได้ ข้อมูลจะส่งเมื่อกลับมาออนไลน์
- ครูประจำชั้นกับครูร่วมใช้ข้อมูลชุดเดียวกันได้ และฝ่ายบริหารเปิดดูในชีตได้โดยตรง

## 🚀 เริ่มใช้งาน (ฝากบน GitHub Pages)

1. สร้าง repository ใหม่บน GitHub เช่น `studentcheck`
2. อัปโหลดไฟล์ `index.html` (และ `README.md`, `Code.gs` ถ้าต้องการเก็บไว้ด้วย)
3. ไปที่ **Settings → Pages**
4. ที่ **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที จะได้ลิงก์รูปแบบ
   ```
   https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/
   ```
6. เปิดลิงก์บนมือถือ แล้วกด **"เพิ่มไปยังหน้าจอหลัก"** จะใช้งานได้เหมือนแอป

> 💡 ทดลองใช้ในเครื่องได้เลยโดยดับเบิลคลิกเปิดไฟล์ `index.html`

### อัปเดตเวอร์ชัน
อัปโหลด `index.html` ตัวใหม่ทับตัวเดิมใน repository ข้อมูลที่บันทึกไว้จะไม่หาย จากนั้นกด **Ctrl+F5** ที่หน้าเว็บเพื่อโหลดตัวใหม่

## 📥 รูปแบบไฟล์ Excel สำหรับนำเข้ารายชื่อ

ใช้แถวแรกเป็นหัวตาราง ระบบจะหาคอลัมน์จากชื่อหัวตารางให้อัตโนมัติ

| เลขที่ | เลขประจำตัว | คำนำหน้า | ชื่อ | นามสกุล |
|:-----:|:----------:|:-------:|------|--------|
| 1 | 31001 | ด.ช. | กิตติพงษ์ | สมบูรณ์ |
| 2 | 31002 | ด.ญ. | ขวัญใจ | มีสุข |

- ใช้คอลัมน์ **"ชื่อ-นามสกุล"** คอลัมน์เดียวแทนก็ได้
- จำเป็นต้องมีแค่คอลัมน์ **ชื่อ** ที่เหลือไม่บังคับ
- ระบบอ่านเฉพาะ**แผ่นงานแรก**ของไฟล์
- เลือกได้ว่าจะ **เพิ่มต่อจากรายชื่อเดิม** (ข้ามเลขประจำตัวที่ซ้ำ) หรือ **แทนที่ทั้งหมด**
- ดาวน์โหลดไฟล์ตัวอย่างได้จากปุ่ม **"⬇ ไฟล์ตัวอย่าง"** ในแท็บ นักเรียน

## ☁️ เชื่อมต่อ Google Sheets

ขั้นตอนละเอียดพร้อมโค้ดที่ใส่รหัสลับให้แล้ว อยู่ในแท็บ **☁️ Google Sheets** ของหน้าเว็บ สรุปได้ดังนี้

1. สร้าง Google Sheets ใหม่ที่ [sheets.new](https://sheets.new)
2. ไปที่เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางโค้ดจากหน้าเว็บ (หรือจากไฟล์ `Code.gs` โดยแก้ `__API_KEY__` เป็นรหัสลับของคุณเอง) จากนั้นกด 💾 บันทึก
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ →** ⚙️ เลือก **เว็บแอป** แล้วตั้งค่าดังนี้

   | ช่อง | ✅ ต้องเลือก | ❌ ห้ามเลือก |
   |---|---|---|
   | ดำเนินการในฐานะ | **ฉัน (อีเมลของคุณ)** | ผู้ใช้ที่เข้าถึงเว็บแอปนี้ |
   | ผู้มีสิทธิ์เข้าถึง | **ทุกคน** | ทุกคนที่มีบัญชี Google |

4. กด **ให้สิทธิ์เข้าถึง** ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย) → อนุญาต**
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) มาวางในหน้าเว็บ ใส่**รหัสลับ**ให้ตรงกับในโค้ด กด **ทดสอบ** แล้วกด **เชื่อมต่อ**
6. **เครื่องอื่นหรือครูร่วม:** ใส่ URL และรหัสลับชุดเดียวกัน แล้วเลือก "ใช้ข้อมูลจาก Google Sheets"

### แผ่นงานที่ระบบสร้างในชีต

| แผ่นงาน | เก็บอะไร |
|---|---|
| ห้องเรียน | ชื่อห้อง ครูประจำชั้น ครูร่วม |
| นักเรียน | เลขที่ เลขประจำตัว ชื่อ-นามสกุล |
| การเช็คชื่อ | การเช็คชื่อโฮมรูมรายวัน และหมายเหตุประจำวัน (studentId = `_note`) |
| รายวิชา | รหัสวิชา ชื่อวิชา ครูผู้สอน |
| เช็คชื่อรายวิชา | การเช็คชื่อแต่ละวิชารายวัน |

> ⚠️ **ทุกครั้งที่แก้โค้ด Apps Script** ต้องไปที่ **จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่** แล้วกดทำให้ใช้งานได้ URL จะยังเหมือนเดิม

## 🛠 แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| **เชื่อมต่อไม่ได้ — ตรวจ URL, อินเทอร์เน็ต และสิทธิ์** | ตั้งสิทธิ์ผิด ต้องเป็น **ดำเนินการในฐานะ: ฉัน** และ **ผู้มีสิทธิ์เข้าถึง: ทุกคน** แล้ว Deploy **เวอร์ชันใหม่** |
| เปิด URL แล้วเจอหน้าล็อกอิน Google | สาเหตุเดียวกับข้อบน |
| ไม่มีตัวเลือก "ทุกคน" | เปลี่ยน "ดำเนินการในฐานะ" เป็น **ฉัน** ก่อน ถ้าใช้บัญชีโรงเรียนแล้วยังไม่มี แปลว่าผู้ดูแลระบบปิดไว้ ให้ใช้ **Gmail ส่วนตัว** สร้างชีตแทน |
| รหัสลับไม่ถูกต้อง | ใช้ค่าใน `const API_KEY = 'sc_…'` จากโค้ด **ไม่ใช่**รหัสการทำให้ใช้งานได้ (AKfycb…) |
| ⚠️ ต้องอัปเดต Apps Script | โค้ดใน Apps Script เป็นรุ่นเก่าที่ยังไม่รองรับรายวิชา ให้คัดลอกโค้ดใหม่ไปวาง แล้ว Deploy **เวอร์ชันใหม่** จากนั้นกด "ซิงก์ตอนนี้" |
| แก้แล้วยังเหมือนเดิม | ยังไม่ได้ Deploy **เวอร์ชันใหม่** ให้กด Ctrl+F5 ที่หน้าเว็บด้วย |

**วิธีตรวจที่เร็วที่สุด:** เปิด URL ของเว็บแอปในหน้าต่างไม่ระบุตัวตน (Ctrl+Shift+N) ถ้าตั้งค่าถูก จะเห็นข้อความ **"StudentCheck API พร้อมใช้งาน ✅"** โดยไม่ต้องล็อกอิน

## 💾 การเก็บข้อมูลและความเป็นส่วนตัว

- **ถ้าไม่เชื่อม Google Sheets:** ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น (localStorage) ถ้าล้างประวัติเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหาย ควรกด **⚙️ ตั้งค่า → สำรองข้อมูล (.json)** เป็นระยะ
- **ถ้าเชื่อม Google Sheets:** ข้อมูลเก็บใน Google Drive ของบัญชีที่สร้างชีต และมีสำเนาในเบราว์เซอร์แต่ละเครื่อง
- ระบบไม่ได้ส่งข้อมูลไปที่อื่นนอกจาก Google Sheets ของคุณเอง
- **ใครมี URL และรหัสลับก็แก้ไขข้อมูลได้** ให้แชร์เฉพาะครูที่เกี่ยวข้อง
- ไฟล์สำรอง (.json) **ไม่มี** URL และรหัสลับติดไปด้วย

## ❓ คำถามที่พบบ่อย

**ส่งข้อความเข้ากลุ่ม LINE อัตโนมัติได้ไหม?**
ยังไม่ได้ เพราะบริการ LINE Notify ปิดไปแล้วตั้งแต่ปี 2025 ระบบจึงสร้างข้อความหรือรูปภาพ แล้วเปิดแอป LINE ให้เลือกกลุ่มส่งเอง (บนคอมพิวเตอร์ใช้วิธีคัดลอกแล้ววางในแชต)

**เช็คชื่อรายวิชาวันละหลายคาบได้ไหม?**
ตอนนี้แต่ละวิชาเช็คได้วันละ 1 ครั้ง

**"อัตรามาเรียน" คิดอย่างไร?**
(มา + สาย) ÷ จำนวนครั้งที่เช็คทั้งหมด × 100

**แก้ข้อมูลในชีตโดยตรงได้ไหม?**
ได้ แต่เครื่องอื่นจะเห็นก็ต่อเมื่อกด **"ดึงข้อมูลทั้งหมดจากชีตใหม่"** ในแท็บ Google Sheets จึงแนะนำให้แก้ผ่านหน้าเว็บ

**ใช้หลายห้องได้ไหม?**
ได้ เพิ่มห้องที่แท็บ นักเรียน → "+ เพิ่มห้องเรียนใหม่" แล้วสลับห้องได้จากมุมขวาบน
